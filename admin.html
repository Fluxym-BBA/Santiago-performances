Créer un compte se fait dans Supabase, en quatre clics

Cette page ne crée pas de compte, et c'est volontaire. Créer un utilisateur exige la clé service_role, qui donne tous les droits sur la base et contourne toutes les règles de sécurité. Elle n'a rien à faire dans un dépôt public, donc elle n'est pas dans cette application. Tout le reste, en revanche, se gère ici.

  1. Supabase → Authentication → Users → Add user → Create new user
  2. Renseigner l'e-mail et un mot de passe provisoire
  3. Cocher Auto Confirm User, sans quoi la personne ne pourra pas se connecter
  4. Valider : le profil apparaît automatiquement dans le tableau ci-dessous

Le nom affiché est déduit de l'adresse e-mail. Il est modifiable ici juste après.

Ce que chaque réglage change vraiment

Rôle administrateur
Accès à la vue d'équipe, à cette page, au sélecteur d'utilisateur de la barre de navigation, et droit de corriger la saisie de n'importe qui. Un BDR ne voit strictement que ses propres lignes, y compris s'il interroge la base directement : la règle est posée dans PostgreSQL, pas dans le navigateur.
Compte de démonstration
Les chiffres du compte sont exclus par défaut de la vue d'équipe et de ses classements. C'est le compte à utiliser pour montrer l'outil sans polluer les statistiques réelles, et sans jamais toucher aux données d'un vrai BDR.
Compte actif
Un compte désactivé ne peut plus se connecter et sort des classements, mais son historique est conservé. C'est la bonne manière de gérer un départ : on ne supprime pas des mois de données pour libérer un accès.
Effacer les données
Supprime les journées d'activité du compte, sans supprimer le compte. Utile pour remettre le compte de démonstration à zéro, ou pour repartir proprement. Sans retour possible.
